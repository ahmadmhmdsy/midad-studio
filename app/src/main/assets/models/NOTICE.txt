On-device AI models and runtime used by Midad Studio
====================================================

Midad Studio runs every AI model on the device. The models below are either
bundled with the app or downloaded only when you choose to install them. This
file credits the models and records their licence. The full Apache License 2.0
text is provided in this directory as LICENSE-Apache-2.0.txt; that copy is the
Apache-2.0 text as distributed in the MediaPipe repository (it includes the
Lucent Technologies / Rob Pike-Ken Thompson appendix).

RUNTIME
-------
This app runs inference with LiteRT 2.3.2 (com.google.ai.edge.litert:litert),
licensed under the Apache License, Version 2.0. Its third-party attributions are
reproduced verbatim in LiteRT-THIRD_PARTY_NOTICE.txt in this directory, and its
AAR license text is in LiteRT-LICENSE.txt (the Android Gradle plugin does not
copy the AAR's root NOTICE into the APK, so the text is shipped explicitly).
No MediaPipe Android library is bundled. Image preprocessing, resizing, softmax
and mask compositing are implemented by Midad Studio.

MediaPipe source files carry the notice: Copyright 2022 The MediaPipe Authors.
MediaPipe repository licence: Apache License, Version 2.0
(https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE).
